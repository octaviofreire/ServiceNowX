# Contexto inicial — ServiceNowX

O ServiceNowX é uma central de serviços técnicos utilizada para registrar chamados, atribuir técnicos, controlar prioridade e SLA, notificar usuários e integrar sistemas externos.

- técnico;
- gestor da central;
- fornecedor externo.

## Sistemas externos inicialmente citados

- monitoramento;
- notificações;
